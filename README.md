# CRM-бот для приёма заявок

Telegram-бот, который собирает заявки клиентов через пошаговую форму, сохраняет их в SQLite и отправляет уведомления администратору. Администратор может просматривать заявки прямо в Telegram и выгружать их в CSV.

## Возможности

- Приветствие по команде `/start` и кнопка «Оставить заявку».
- Пошаговый сбор данных через FSM: имя → задача → контакт.
- Сохранение заявки в базу данных SQLite (`requests.db`).
- Мгновенное уведомление администратора о новой заявке.
- Админ-панель по команде `/admin`:
  - просмотр всех заявок;
  - экспорт заявок в CSV-файл.
- Проверка прав: админ-функции доступны только пользователю с `ADMIN_ID`.
- Отмена заполнения формы командой `/cancel` или кнопкой «Отмена».

## Стек

- Python 3.10+
- [aiogram](https://docs.aiogram.dev/) 3.x
- `sqlite3` (встроенный модуль Python)
- `python-dotenv`

## Структура проекта

```text
.
├── main.py           # точка входа, запуск polling
├── config.py         # загрузка BOT_TOKEN и ADMIN_ID из .env
├── database.py       # инициализация SQLite и работа с заявками
├── handlers.py       # команды, FSM, админ-панель, экспорт в CSV
├── requirements.txt  # зависимости проекта
├── .env.example      # пример файла с настройками
├── .gitignore
└── README.md
```

## Установка

1. Убедитесь, что установлен Python 3.10 или новее:

   ```bash
   python --version
   ```

2. Клонируйте проект или перейдите в его папку.

3. (Рекомендуется) Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

   Windows (PowerShell):

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   Linux / macOS:

   ```bash
   source .venv/bin/activate
   ```

4. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

## Настройка

1. Создайте файл `.env` на основе `.env.example`:

   ```bash
   cp .env.example .env
   ```

   Windows (PowerShell):

   ```powershell
   Copy-Item .env.example .env
   ```

2. Получите токен бота у [@BotFather](https://t.me/BotFather) и укажите его в `.env`:

   ```dotenv
   BOT_TOKEN=123456789:AAExampleTokenFromBotFather
   ADMIN_ID=123456789
   ```

   `ADMIN_ID` — ваш Telegram ID. Его можно узнать, например, у бота [@userinfobot](https://t.me/userinfobot).

3. Сохраните файл. Файл `.env` уже добавлен в `.gitignore` и не попадёт в репозиторий.

## Запуск

```bash
python main.py
```

После запуска откройте бота в Telegram, отправьте `/start` и нажмите «Оставить заявку».

Для остановки нажмите `Ctrl+C`.

## Использование

### Пользователь

1. Отправляет `/start`.
2. Нажимает «Оставить заявку».
3. Вводит имя, описание задачи и контакт.
4. Получает подтверждение с номером заявки.

### Администратор

1. Отправляет `/admin`.
2. Нажимает «Посмотреть заявки» — бот присылает список заявок (при большом количестве — несколькими сообщениями).
3. Нажимает «Экспорт в CSV» — бот присылает файл `requests.csv` с разделителем `;` в кодировке UTF-8 с BOM (корректно открывается в Excel).

## База данных

Данные хранятся в файле `requests.db`, который создаётся автоматически при первом запуске. Таблица `requests` содержит поля:

| Поле         | Тип     | Описание                       |
|--------------|---------|--------------------------------|
| `id`         | INTEGER | Первичный ключ, номер заявки   |
| `user_id`    | INTEGER | Telegram ID пользователя       |
| `name`       | TEXT    | Имя пользователя               |
| `task`       | TEXT    | Описание задачи                |
| `contact`    | TEXT    | Контакт для связи              |
| `created_at` | TEXT    | Дата и время создания заявки   |

Файлы `*.db` исключены из Git через `.gitignore`.
